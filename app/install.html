把穿搭灵感，放在主屏幕

200 套男生穿搭 · 厚度筛选 · 左右划卡
需要联网。无需账号，个人选择保存在当前设备。

iPhone / iPad

  1. 用 Safari 打开下方「开始使用」链接。
  2. 点浏览器的分享按钮，选择添加到主屏幕。部分版本可先从菜单进入分享。
  3. 如有「作为 Web App 打开」选项，保持开启，再点添加。

Android

  1. 用 Chrome、Edge 或支持安装的手机浏览器打开网站。
  2. 在菜单中选择安装应用或添加到主屏幕，按提示完成。不同浏览器名称可能不同。
开始使用 →

如果在微信等应用内打开，请先选择「在浏览器中打开」。添加后首次打开，请确认收藏是否保留；不同系统或浏览器的存储环境可能独立，可通过「偏好」导出、导入备份。

当前版本不提供离线功能。建议先看几套，遇到厚度或其他标签不准时，在卡片内记录问题，几天后连同选择一起导出。
