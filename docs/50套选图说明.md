# 50套整套穿搭试用版

本批从 MUSINSA 韩国男生用户公开穿搭帖筛选，替换此前200张图库。用户已确认优先保证图片质量，接受公开穿搭社区来源；本批不声称来自 Instagram。

从男生用户、冬季关键词的热门列表收集91个候选帖，核实选中帖的作者、出处和媒体图片，再由GPT查看本地审核图、逐张筛选并标注。最终50套来自43位作者，同一作者最多3套；使用4张原帖相册中更完整的全身角度，排除局部特写、单品平铺、拼图与重复角度。原帖点赞数按采集时实际记录，未设置高赞门槛，不保证每帖高赞。

厚度：厚暖15套、适中35套，不包含轻薄夏装。厚暖主要为长大衣、棉服、绒感或绗缝外套；适中包括针织、皮夹克和西装等。厚度仅按可见造型粗分，不代表真实材质克重或保暖性能；适中搭配在冬天可能需要加外套。现有厚度筛选保留，初次使用默认厚暖，清除筛选可查看全部50套。

保留原有风格、配色、轮廓、搭配方式、季节与厚度六维筛选；每张均保留真实原帖链接。图片继续从原站加载，没有把他人摄影作为开源图片资产上传，也没有新增在线AI调用或费用。原站调整、网络或防盗链可能导致图片失效，保留重试及出处入口；中国大陆真实手机多运营商尚未实测。

旧图库选择继续保留在当前浏览器的记录与导出备份中，不显示在新图库收藏、不计入新进度。旧记录仍可随备份恢复；新图库偏好仅按当前50套统计。清除全部选择会同时清除旧记录，操作前仍有确认提示。

采集候选、原帖审核证据、下载预览和测试备份只在本地 outputs/v3，不上传。公开采集代码是一次性准备程序，没有创建定时任务、账号或云数据库。可使用 OUTFIT_PROXY 指定已有网络代理，不切换身份或绕过平台验证。

Instagram检查结论：此前普通连接超时是本机命令未使用系统已有代理所致；修正后读取到官方robots规则，当前不适合按本项目采集约定批量读取。Chrome浏览器接管仍出现Debugger unattached，不能把连接问题解释为未登录。未安装完成Agent-Reach，未导出或复制用户登录凭据。
