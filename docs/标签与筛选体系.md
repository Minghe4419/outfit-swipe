# 韩系男生整套穿搭：标签与筛选

内容范围固定：韩系男生、整套搭配、发现风格。韩系为编辑选题和来源背景，不推断人物国籍。

| 维度 | 初始标签 | 含义 |
|---|---|---|
| 风格 style | 简约、休闲、通勤、复古 | 可多选；仅为人工对照片氛围的解释 |
| 配色 palette | 黑白灰、大地色、蓝色系、浅色系、亮色点缀 | 整体配色，允许复合；蓝色牛仔搭白上衣可同时属于浅色系 |
| 轮廓 silhouette | 宽松、利落 | 主要服装轮廓；不推断尺码或身材合适程度 |
| 搭配方式 layering | 叠穿、简洁单层 | 可见服装搭配层次 |
| 季节 season | 春秋、夏季、秋冬 | 视觉上的穿衣厚度参考，不是保暖保证 |

不同维度 AND，同维度 OR。零结果时提示清除条件，不自动放宽硬筛选。候选不足时保留空状态，不重复推送已划卡片。

标签人工核对，不声称用 AI 自动识别。每张图片保留源站和独立出处。整套图的反馈只更新整体维度，不推断喜欢其中每件单品。

# 排序

喜欢 +1、想穿 +2.5、不喜欢 -0.15；按每维度标签数归一。每张卡片只有一个当前状态，收藏切换按最终状态重新计算。撤销恢复之前的状态，不累计重复学习。

按未看、符合筛选的候选计算标签权重相似分数；每五张留一个原始编辑序列的探索项（如有足够候选）。这是透明规则排序，不是训练的机器学习模型。20 张数据只用于体验机制，不能代表韩系男装完整分布。
